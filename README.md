# React Posts & Categories UI

A modern frontend component showcase built with **React.js** and **Vite**, focusing on foundational React concepts including component architecture, props destructuring, children prop composition, and dynamic list rendering.

---

## 🔗 Links

- **Repository:** [GitHub Repository](https://github.com/Ali-Tobar/react-posts-feed)

---

## ✨ Key React Concepts Applied

- **Functional Components:** Modular UI split into `Header`, `Post`, `SideMenu`, and `TagButton`.
- **Props & Destructuring:** Passing and consuming data cleanly across components.
- **Children Prop:** Implementing flexible component composition using React's `children`.
- **List Rendering:** Rendering dynamic collections of data using `.map()` with unique `key` props.

---

## 🛠️ Built With

- **React 18 / 19**
- **Vite** (Build tool and development server)
- **CSS3** (Component-level styling)
